# ЧебуТап-бот — нейросотрудник в Telegram

Принимает задачи по упоминанию в чате и выполняет их через Claude Code на сервере, круглосуточно.

## Как работает

1. В группе: `@имя_бота сделай …` (или в личке боту — просто текст).
2. Бот присылает план: что изменится и как это будет работать, какие файлы затронет. Кнопки **✅ Делать** / **❌ Отмена**; ответ на план — правки, бот переделает план.
3. После «Делать»: ветка `bot/<id>` от свежего `main` → Claude правит код, запускает lint/build, коммитит → бот сам проверяет `npm run build` и пушит ветку.
4. Ветка уходит в `main` (rebase, без force-push) → ждёт workflow `deploy.yml` → smoke-проверка `APP_URL`.
5. Отчёт в чат: что сделано, ссылки на деплой и коммит, стоимость. Если деплой или smoke упали — бот делает `git revert` в `main` и сообщает.

`#без_деплоя` в тексте задачи — только ветка, без выката. Команды: `/status`, `/cancel`, `/id`, `/help`.

Задачи выполняются по одной, остальные ждут в очереди. Ставить и утверждать задачи могут только пользователи из `BOT_ALLOWED_USER_IDS`.

## Настройка (один раз)

1. **Бот.** В @BotFather: `/newbot` → токен. Затем `/setprivacy` → бот → **Disable**, чтобы бот видел упоминания в группах. Добавьте бота в нужную группу.
2. **Доступ к Claude** — одно из двух:
   - подписка Claude Pro/Max: на своём компьютере `claude setup-token` → токен в секрет `CLAUDE_CODE_OAUTH_TOKEN`;
   - ключ API из console.anthropic.com → секрет `ANTHROPIC_API_KEY` (оплата по токенам).
3. **GitHub-токен.** github.com → Settings → Developer settings → Fine-grained tokens: только репозиторий `chebutap`, права **Contents: Read and write**, **Actions: Read**. Секрет `BOT_GITHUB_TOKEN`.
4. **Свой Telegram id.** Временно можно взять у @userinfobot. Секрет `BOT_ALLOWED_USER_IDS` (несколько — через запятую). Необязательно: `BOT_ALLOWED_CHAT_IDS` — id групп (бот покажет по `/id`), `APP_URL` — адрес игры для smoke-проверки.
5. Добавьте эти секреты в GitHub: репозиторий → Settings → Secrets and variables → Actions. Секреты сервера и Docker Hub (`SERVER_*`, `DOCKERHUB_*`) уже есть — их использует деплой игры.
6. Запустите workflow **Bot → Docker Hub → Server** (Actions → Run workflow) или запушьте изменения в `bot/`. Бот поднимется в контейнере `chebutap-bot` в `<SERVER_DEPLOY_PATH>/bot` с `restart: unless-stopped`.

Проверка на сервере: `docker logs -f chebutap-bot` — строка «Бот @… запущен».

## Безопасность

- Claude в контейнере работает с полным доступом к файлам и командам (`--dangerously-skip-permissions`), поэтому задачи принимаются только от разрешённых пользователей.
- Токены Telegram и GitHub не передаются в процессы Claude; GitHub-токен используется только в заголовке команд `git push/fetch`. Изоляция не абсолютная (тот же пользователь в контейнере), поэтому выдавайте токен GitHub только на этот репозиторий.
- Force-push бот не делает никогда.

## Ограничения

- Очередь и ожидающие планы хранятся в памяти: после перезапуска контейнера их нужно поставить заново (клон репозитория и сессии Claude сохраняются в томе).
- Макет-картинку для дизайн-задач бот не рисует — план описывает изменения словами.
- Изменения в `bot/` выкатываются отдельным workflow; бот перезапустится и прервёт текущую задачу.
