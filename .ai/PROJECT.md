# Проект: ЧебуТап (ChebuTap)

Обновлено: 2026-10-31. Основание: исходники и конфигурация на базе `de8bd57`.

## Что создаём

Казуальная Telegram Mini App в жанре tap-to-earn: игрок нажимает на монету с персонажем,
расходует энергию, получает монеты, выполняет задания, покупает улучшения и здания
для пассивного дохода. Визуальный стиль — зелёный фон, деревянные элементы,
графика из Figma. Основной сценарий — мобильный Telegram WebView; доступен браузерный запуск.

Текущая реализация — клиентский прототип. Игровой баланс и прогресс считаются на устройстве.
Сервер, база данных, синхронизация аккаунтов и реальные платежи в репозитории не реализованы.
Термин tap-to-earn здесь означает игровую механику, а не подтверждённый денежный заработок.

## Пользовательские возможности

| Раздел | Реализация |
| --- | --- |
| earn | Тап, монеты, энергия, множитель, кнопки Boost/shop |
| tasks | Пять заданий с прогрессом и однократными наградами |
| town | Четыре типа зданий, доход в монетах в секунду |
| upgrades | Сила тапа, максимум энергии, регенерация |
| account | Данные Telegram при наличии, статистика, ссылка приглашения, сброс |
| Модальные окна | Бусты, обмен игровой валюты/энергии, настройки |

## Стек и запуск

- React 19, TypeScript, Vite 8, `@twa-dev/sdk`; точные диапазоны — `package.json`, разрешённые версии — `package-lock.json`.
- Состояние: React hook `useGameStore`; сохранение: `localStorage`.
- Стили: обычный CSS в `src/index.css`, ассеты в `public/`.
- Проверки: TypeScript через сборку, Oxlint через `npm run lint`.
- Доставка: Docker (Node 22 build → Nginx), GitHub Actions → Docker Hub → SSH/Compose.

Из корня репозитория:

```bash
npm ci
npm run dev
npm run lint
npm run build
npm run preview
```

Для разработки используй Node, совместимый с текущим lockfile и Vite; ориентир сборки — Node 22 из Dockerfile.
Dev-сервер обычно печатает адрес с портом 5173; фактический URL смотри в терминале.
Для открытия Mini App в Telegram нужен доступный HTTPS URL и настройка приложения через BotFather.
Bot token для запуска текущего фронтенда не требуется.
