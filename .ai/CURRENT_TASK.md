# Текущая задача: Telegram Wallet и иконки из Figma

Обновлено: 2026-11-03. Статус: кошелёк и нижнее меню исправлены, не опубликованы.

## Цель и границы

1. Устранить ошибку «Не удалось открыть подключение» при нажатии «Подключить DeFi Wallet» в Telegram (скриншот пользователя, Android). Маршрут Walt/TON Connect не менять.
2. Поправить иконки по Figma — после получения ссылки на файл/узел.

## Критерии готовности

- В Telegram кнопка открывает Walt нативным `openTelegramLink`, без ошибки; в браузере — модалка TON Connect.
- lint/build без новых предупреждений.
- Иконки соответствуют указанному узлу Figma.

## Результат

Причина — CJS-interop `@twa-dev/sdk` (`{ default: WebApp }`); исправлено через `src/lib/telegram.ts`. Lint/build PASS, браузерная эмуляция Telegram PASS. Устройство и подтверждение в Walt не проверены. Нижнее меню по Figma `3:946` выровнено: равные поля и промежутки, общий top, иконки по центру; замер в браузере 390/320px PASS.
