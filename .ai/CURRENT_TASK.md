# Текущая задача: подключение кошелька через TON Connect

Обновлено: 2026-11-01. Статус: реализовано; ожидается проверка реальным кошельком.

## Цель и границы

Заменить переход к Wallet реальным TON Connect: выбор кошелька, подтверждённый адрес, восстановление сессии и отключение на главном экране. Сессию ведёт официальный SDK отдельно от игрового сохранения. Серверная авторизация и транзакции не входят в задачу.

## План и критерии готовности

1. Добавить официальный React SDK и provider на уровне приложения.
2. Заменить старый обработчик отдельным компонентом подключения с адресом и отключением.
3. Предоставить публичный HTTPS manifest с абсолютными URL для текущего домена в Nginx; поддержать локальный Vite и статический build с VITE_APP_URL.
4. Выполнить lint/build, проверить manifest и зафиксировать ограничения.

## Результат

Реализованы provider, официальный SDK, выбор кошелька, восстановление сессии, сокращённый адрес, панель полного адреса и отдельная кнопка отключения. Отказ/закрытие окна не создаёт фиктивного подключения. Ошибки SDK отображаются пользователю.

Для Docker/Nginx manifest выдаётся с текущим HTTPS доменом. Для другого статического хостинга требуется `VITE_APP_URL=https://публичный-домен` при build. Локальный HTTP поддерживает интерфейс, но подтверждение в кошельке требует публичного HTTPS.

Проверки: lint PASS (2 прежних Date.now предупреждения); TypeScript/Vite build PASS, включая вариант VITE_APP_URL с проверкой JSON manifest. Vite сообщает bundle >500kB (809kB minified / 245kB gzip). diff-check PASS. HTTP-проверка preview заблокирована sandbox socket permissions; реальный Telegram и подтверждение пользовательским кошельком не проверялись.

Изменены: package.json/package-lock.json, src/main.tsx, src/screens/GameScreen.tsx, src/components/WalletConnect.tsx, src/index.css, vite.config.ts, deploy/nginx.conf, .ai/CURRENT_TASK.md, .ai/ARCHITECTURE.md. Общие STATE/CHANGELOG обновляет основной агент.

Проверка TON Connect reviewer: PASS после исправления перекрытия баланса; геометрия проверена по CSS для ширины 320 и 390px. Визуальная проверка и подтверждение кошельком не выполнены.
